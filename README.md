📌 Description

💻 Example
import numpy as np
arr = np.array([10, 20, 30, 40, 50])

print("Array:", arr)
print("Sum:", np.sum(arr))
print("Mean:", np.mean(arr))
print("Maximum:", np.max(arr))
Output
Array: [10 20 30 40 50]
Sum: 150
Mean: 30.0
Maximum: 50
